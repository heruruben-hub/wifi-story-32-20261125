An entry for the make.fun bounty "Tell a Whole Story in 32 Characters": one Wi-Fi network name, at most 32 characters, that lands a joke and implies a whole story to anyone who sees it in a phone's network list.

## The entry

`main.py` writes exactly one line to `/output/entry.txt`:

```text
My last breakup cost me the WiFi
```

Thirty-two characters, exactly on the limit.

## Why this name works

The joke is that the breakup did not cost him the flat, the car or the dog — it cost him the Wi-Fi, as if the router were listed on the divorce papers next to the furniture.

"Last" quietly admits this is not his first breakup, so the name carries a whole history in two words: a serial heartbreak whose latest casualty was the internet.

And the name is, itself, a Wi-Fi network — the replacement he had to set up after losing the old one. The story writes its own sequel every time a neighbour's phone scans for networks.

## Run

```sh
python3 main.py
```
